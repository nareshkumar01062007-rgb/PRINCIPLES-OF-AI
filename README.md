# Principles of Artificial Intelligence

This repository contains the implementation of different types of Artificial Intelligence (AI) agents using Python. Each project demonstrates the working principle of a specific AI agent with a Smart Light example.

## Projects

### 1. Simple Reflex Agent
- Makes decisions based only on the current input.
- Folder: `Simple-Reflex-Agent`

### 2. Model Based Agent
- Uses the current input and previous state (memory) to make decisions.
- Folder: `Model-Based-Agent`

### 3. Goal Based Agent
- Makes decisions to achieve a specific goal.
- Folder: `Goal-Based-Agent`

### 4. Utility Based Agent
- Chooses the best possible action based on utility or user preference.
- Folder: `Utility-Based-Agent`

### 5. Learning Agent
- Learns from previous experiences and improves future decisions.
- Folder: `Learning-Agent`
