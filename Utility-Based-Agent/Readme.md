# Smart Light using Utility Based Agent

## Objective
To simulate a Smart Light using a Utility Based Agent.

## Input
Light intensity and user preference.

## Output
The light operates in the most useful mode (Bright, Dim, or OFF).

## Algorithm
1. Read the light intensity.
2. Check the user preference.
3. Select the best lighting mode.
4. Display the result.

## Result
The Smart Light is successfully implemented using a Utility Based Agent.
