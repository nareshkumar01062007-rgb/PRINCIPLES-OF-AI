# Smart Light using Model Based Agent

## Objective
To simulate a Smart Light using a Model Based Agent.

## Input
Light intensity / Motion detection.

## Output
Light turns ON or OFF based on the current and previous state.

## Algorithm
1. Read the current light intensity.
2. Check the previous state of the light.
3. Decide whether the light should be ON or OFF.
4. Display the result.

## Result
The Smart Light is successfully implemented using a Model Based Agent.
