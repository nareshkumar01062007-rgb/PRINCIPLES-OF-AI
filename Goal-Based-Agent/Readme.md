# Smart Light using Goal Based Agent

## Objective
To simulate a Smart Light using a Goal Based Agent.

## Input
Light intensity and user goal.

## Output
Light turns ON or OFF to achieve the required goal.

## Algorithm
1. Read the light intensity.
2. Check the user goal.
3. Decide whether the light should be ON or OFF.
4. Display the result.

## Result
The Smart Light is successfully implemented using a Goal Based Agent.
