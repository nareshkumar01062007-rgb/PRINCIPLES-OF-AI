# Smart Light using Learning Agent

## Objective
To simulate a Smart Light using a Learning Agent.

## Input
Light intensity.

## Output
The light turns ON or OFF and learns from the current situation for future decisions.

## Algorithm
1. Read the light condition.
2. Turn the light ON if it is dark.
3. Turn the light OFF if there is enough natural light.
4. Store the experience as learning for future use.
5. Display the result.

## Result
The Smart Light is successfully implemented using a Learning Agent.
